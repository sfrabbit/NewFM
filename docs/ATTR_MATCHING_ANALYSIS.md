## 模块1: Pass (传球)

### 研究发现的判定需求
| 判定需求 | 现实依据 | 匹配属性 | 匹配度 | 问题 |
|---------|---------|---------|--------|------|
| 持球前扫描周围环境 | 眼动追踪研究 | 足球理解？队友识别？ | ⚠️ 模糊 | 没有直接的"视野"或"扫描"属性 |
| 识别防守漏洞 | 战术理解 | 足球理解 | ✅ 匹配 | - |
| 预判队友跑位 | 配合默契 | 队友识别 | ✅ 匹配 | - |
| 预判防守者拦截意图 | 对手阅读 | 对手识别 | ✅ 匹配 | - |
| 决策时机（犹豫惩罚） | 常见错误分析 | 决断速度 | ✅ 匹配 | - |
| 视野疲劳 | 视觉疲劳研究 | 集中力？ | ⚠️ 间接 | 没有"视野耐力"属性 |

### 问题识别
**问题1**: "提前观察/扫描"机制没有直接对应的属性
- 候选：足球理解（比赛阅读）vs 集中力（注意力）
- 建议：**用足球理解**，因为比赛阅读包含扫描能力

**问题2**: 视野疲劳没有对应属性
- 候选：集中力（精神疲劳）vs 耐力（体能疲劳）
- 建议：**用集中力**，因为视觉注意力属于精神层面

**结论**: Pass模块可以用现有属性实现，无需新增

## 综合结论

### 可以完全用现有属性实现的模块
1. **Pass** - 足球理解+队友识别+对手识别+决断速度
2. **Tackle** - 对手识别+决断速度+足球理解+防守技术
3. **Contest** - 足球理解+决断速度+爆发+空中能力
4. **Save** - 对手识别+瞬间反应+足球理解

### 需要讨论的模块
| 模块 | 问题 | 建议方案 |
|-----|------|---------|
| **Dribble** | 假动作机制 | 用控制技巧+自信组合，或新增"欺骗性"属性 |
| **Shoot** | 博弈层（习惯/反习惯） | 设计学习系统，非属性问题 |

### 需要新增属性的情况
**候选新增属性**（需你决策）：

| 属性名 | 用途 | 替代方案 |
|-------|------|---------|
| 视野/扫描 | Pass提前观察 | 用足球理解替代 |
| 欺骗性/假动作 | Dribble假动作 | 用控制技巧+自信替代 |
| 预判准确性 | 所有模块的预判效果 | 用现有属性组合 |

### 建议
**不新增属性**，原因：
1. 20属性已经较多，增加复杂度
2. 研究发现的判定都可以用现有属性组合实现
3. "假动作"等边缘情况可用组合属性覆盖

**实施方案**：
- 用**足球理解**覆盖比赛阅读、空间感知、轨迹预判
- 用**对手识别**覆盖阅读意图、习惯识别
- 用**队友识别**覆盖跑位预判
- 用**决断速度**覆盖时机选择
- 用**集中力**覆盖精神疲劳
