## 5. 引擎公式校准结论

### 5.1 传球公式

| 场景 | 测试值 | 现实参考 |
|------|--------|----------|
| 高属性 5m | 99% | 顶级短传 >95% |
| 中等属性 5m | 90% | 联赛平均 ≈90% |
| 高属性 40m | 82% | 顶级长传 ≈75-80% |
| 中等属性 40m | 61% | 平均长传 ≈50-55% |
| 高属性 90m | 42% | 偏远端长传 |
| 力量倾向 40m vs 精度 | 68% vs 54% | 长传需要力量 |

**结论：符合现实。** Mean pass success 83.5% (StatsBomb)，5m短传约90-95%合理。

### 5.2 盘带公式（基础版）

| 场景 | 测试值 | 现实参考 |
|------|--------|----------|
| 高属性 vs 中等防守（无压力） | 63% | 多库60.5%、穆西亚拉62% |
| 高属性 vs 高防守（无压力） | 50% | 联赛平均 ≈50% (StatsBomb) |
| 中等 vs 中等（轻度压力） | 47% | 中游球员 |
| 低属性 vs 高防守（高压） | 22% | 加纳乔29.3%、萨拉赫低点12.5% |

**结论：符合现实。** StatsBomb平均盘带成功率50.2%，顶级球员55-65%，弱势球员12-30%。

### 5.2b 盘带分支公式（校准版，2026年6月）

**公式核心：**
```
baseSuccess = playerScore / (playerScore + risk * defenderScore)
spaceFactor = max(0.3, 1 - spaceSensitivity * max(0, 5 - space))
pressureFactor = max(0.5, 1 - pressureLevel * 0.08)
fatigueFactor = max(0.7, 1 - fatigue * 0.005)
finalRate = baseSuccess * spaceFactor * pressureFactor * fatigueFactor
```

**关键改动（vs 旧版）：**
1. spaceFactor 从 `space/5`（所有分支统一）改为 `1 - sensitivity * (5-space)`（每分支独立敏感度）
2. pressureFactor 从乘法放大 `1 + pressure*0.15` 改为线性衰减 `1 - pressure*0.08`
3. pressureFactor 从放在 baseSuccess 分母内改为独立因子
4. 每个分支情境有独立的 spaceSensitivity 参数

**测试结果 12/12 全部通过：**

| 验证项 | 公式值 | 现实范围 | 状态 |
|--------|--------|----------|------|
| D1 高属性无压力推进 | 87.6% | >80% | ✓ |
| D2 顶级单对一 | 59.5% | 55-70%（贝林厄姆63.8%） | ✓ |
| D2 中等单对一 | 52.7% | 42-58%（联赛平均50%） | ✓ |
| D2 弱队单对一 | 44.0% | 28-45%（英超U23:38%） | ✓ |
| D3 高属性护球牵制 | 59.1% | 45-70%（意甲前锋52%） | ✓ |
| D3 中等属性回传 | 61.3% | 55-75%（回传安全>60%） | ✓ |
| D3 高压强行突破 | 36.4% | 15-40%（高压困难） | ✓ |
| D4 顶级边锋内切 | 61.1% | 58-78%（王钰栋72%） | ✓ |
| D4 弱队边线突破 | 46.2% | 30-50%（利兹联39%） | ✓ |
| D5 有核心反击冲刺 | 76.5% | 70-90% | ✓ |
| D5 无核心反击冲刺 | 58.3% | 45-65% | ✓ |
| 疲劳影响 | 76.5%→53.6% | 降幅>10% | ✓ |

### 关键校准锚点

1. **D2单对一**：联赛平均约50%，顶级55-63%，弱队38%
2. **D3护球**：正常50-65%，围抢下出球降至30%左右，但护球本身（不丢球）应更高
3. **D3回传**：回传是安全选项，成功率应远高于强行突破（>60%）
4. **D4边线**：顶级边锋60-72%，普通39-55%
5. **D5反击**：有核心40%+，无核心可低至17-28%
